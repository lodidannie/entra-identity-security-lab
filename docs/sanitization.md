# Sanitization and publication review

This package was constructed from selected settings, not by copying the original DOCX. Private identity-to-alias mappings are excluded. Original employer names and employee/group labels are absent from deliverable content. Fictional examples are explicitly labeled.

Before adding evidence:

- Replace names, UPNs, tenant domains, group names, GUIDs, tenant IDs, URLs containing identifiers, policy IDs, application IDs and resource names.
- Remove tokens, secrets, recovery details, authentication QR codes, sign-in IP addresses and sensitive risk or incident information.
- Flatten image redactions so covered text cannot be recovered. Crop browser chrome where it reveals account or organization details; inspect the full image.
- Export clean text or images instead of shipping the original document with comments, revision history, hidden data or metadata.
- Preserve only necessary configuration details and mark every reconstruction illustrative.
- Confirm organizational authorization before publishing production-derived material. Sanitization is not itself publication permission.

The current package contains no raw screenshots, logs, original report or source mapping. It is a reviewable GitHub upload package; nothing has been published externally.
